# Arrow GO v3 corrective direction package

## Decision header

```text
Game / slice: Arrow GO (`com.reda.arrow`) evidence-bounded square mode
Reference target: current first-party Google Play listing and screenshots, version 1.0
Starting commit: 3e561fb3c55f3b0b813da2b9ee9468cd4d290bae
Runtime / platform: Godot 4.6, Web / desktop
Viewport and device class: 540 × 960 portrait, touch / pointer / keyboard
Direction status: approved under catalog-cartoon-v1 and the owner's autonomous rollout command
Prepared at: 2026-08-21
```

This package replaces the v2 courier-to-harbor metaphor because Stage 0 proved
that metaphor described neither the requested product nor its rules. It keeps
the approved catalog pillars—read the move, feel the craft, earn the peak;
tactile cartoon materials, authored edge world, metaphor-bound motion—while
binding them to the corrected mechanic.

## Baseline, evidence and invariants

The lawful target identity and evidence boundary are frozen in
`docs/replica/arrow-go-v3/target-manifest.md`. First-party facts establish a tap
on an arrow, movement in its own direction, blocking/order, clear-all, a hidden
animal, and square/circle/triangle modes. Exact level data, collision kernel,
score, failure, progression and recovery remain unknown. The local 12-arrow
square level and rigid full-body sweep are therefore bounded clean-room
decisions, not claims about a target build.

| Probe | Frozen local behavior | Evidence |
|---|---|---|
| Entry | 12 unique connected orthogonal arrows; legal set `b,d,k` | `tools/arrow_go_v3_contract_smoke.gd` |
| Input/order | pointer, touch and keyboard issue the same arrow-id command; a blocker must leave first | contract and runtime smoke |
| Mutation | blocked attempt is atomic; legal attempt removes exactly one identity | contract smoke |
| Result/failure | clear all reveals the animal; synthetic local deadlock loses; terminal states freeze | contract smoke |
| Restart/recovery | restart is canonical; only strict versioned active histories restore | contract and runtime smoke |

Stage 0 decision: mechanics production passed for this bounded slice; target
fidelity remains `PARTIAL`, and surpassing the reference is `NOT_CLAIMED`.

## Pillars and anti-pillars

### Experience pillars

| Pillar | Player intent | Production consequence | Observable proof |
|---|---|---|---|
| Read the arrow | know which whole object acted and why it stopped or left | feedback begins on the selected polyline and first contact, never only in a toast | blocked and legal event sequences |
| Uncover the friend | experience each clear as removing a physical layer over a hidden animal | the GAG fox is visible beneath the opening array and becomes unobstructed through real removals | stable, eight-clear and win frames |
| Earn the reveal | preserve contrast between a routine clear and the final uncovering | short paper glide for routine actions; semantic promotion at 4/8, last two and clear-all | grade and continuous-peak probes |

### Art pillars

| Pillar | Shape / material / motion rule | Observable proof |
|---|---|---|
| Sticker-diorama craft | chunky laminated arrows, rounded joins, contact shadow and cream paper board surround one cut-paper animal | readable stable frame without title |
| Live path authority | every arrow path, bend, direction, focus and removal is code-native; generated art contains no board state, text or symbols | model snapshot matches all rendered identities |
| Directional extraction | the whole acted-on polyline compresses, then exits in its authoritative direction and settles into a newly readable board | intent → anticipation → impact → settle sequence |

### Anti-pillars

| Reject | Reason | Counterexample |
|---|---|---|
| Courier, harbor or destination journey | describes the disproved v2 rules | player token moving cell-by-cell toward `[8,8]` |
| Baked puzzle screenshot | can lie about topology and input | AI image containing arrows, score, buttons or labels |
| Equal celebration on every tap | erases ordering tension and accessibility | full shake, bells and confetti on a routine clear |

## Fantasy, tone and visual system

- Player fantasy: peel a cheerful paper arrow tangle away to reveal the fox
  hiding underneath.
- Tone: calm tactile discovery that grows into a warm final reveal.
- Style words: crafted, legible, playful. Anti-words: neon, ornamental, noisy.
- Signature motif: a GAG-authored coral-and-cream fox under multicolor laminated
  arrow paths on a dotted cream paper board.
- Shared shell relationship: the violet suite header frames the game; the bright
  paper playfield and fox own the visual identity.

Shape grammar uses 11 px rounded path bodies, oversized code-native arrowheads,
and a six-color family. Shadows offset down-right; slim cream highlights make
the arrows feel laminated rather than flat. Dynamic Chinese copy uses the CJK
UI/display roles. No generated text or symbol is shipped.

## GAG visual development

Fresh semantic search was performed first on the verified HOME-WSL service.
The highest animal candidates were clothed detective foxes with props and baked
RGB checkerboards; board candidates were card frames, stone test maps or full
card images; audio candidates were cat-paw completion, fruit cascade, generic
accept/coin/magic cues or long music. All were rejected for role, state or style
mismatch.

GAG pure API then produced one isolated fox through fal.ai Flux Pro v1.1,
Remove.bg and deterministic crop/scale. It is first visible on the untouched
board at 172 px and remains present in every ordinary state. ElevenLabs produced
three variations each for arrow escape and fox reveal. Variation 3 of escape
and variation 2 of reveal were selected using measured duration, loudness,
true peak and silence; no subjective listening claim is made. Exact prompts,
scores, QA and hashes are in `arrow-go-v3.gag-asset-ledger.json`.

## Feedback grammar

| Semantic result | Object / world response | Audio / haptic / camera | Settled consequence |
|---|---|---|---|
| blocked | selected arrow recoils at its first blocker; contact cross marks the collision | bounded reject cue and grade-2 haptic; no state mutation | the same arrow remains and blocker identity is readable |
| straight escape | short compression then whole-arrow directional exit | frequent GAG paper-whoosh, light haptic, no camera peak | exactly one arrow is absent |
| bent escape / 4 or 8 clears | bent identity travels intact; local rings expose newly legal space | pitched escape cue and stronger bounded response | newly opened order is readable |
| last two | fox and remaining paths gain the strongest nonterminal hierarchy | grade-3 response, still below completion | next legal arrow remains unobscured |
| clear-all | final arrow leaves; central fox becomes full-strength and result plaque settles | separate GAG reveal cue and grade-4 response | remaining `0`, won state and restart affordance |
| local deadlock | no celebratory displacement; failure state is preserved | reject/failure response only | terminal local-loss overlay |

Reduced effects retain the same immediate authoritative removal and labels but
disable board shake, displacement, catalog particles and haptics. A fading
same-position ghost replaces travel. The `prefers-reduced-motion` query selects
this path on Web.

## Production and claim boundary

- Rule owner: `models/arrow_go_model.gd`; rendering never recomputes legality.
- Runtime derivatives only ship; source masters remain in HOME-WSL GAG.
- Legacy v1 wind/courier/harbor and kite/dock assets are explicitly excluded
  from Web export and have zero v3 runtime role.
- Web acceptance requires a clean fingerprinted archive, real pointer/touch/
  keyboard actions, reload recovery, restart, reduced-effects, headers/range/
  full transfer and zero console/request errors.
- Art strengthening and expressive strengthening may be assessed against the
  disproved local baseline. Target fidelity is `PARTIAL`; breakthrough and
  superiority over the commercial reference are `NOT_CLAIMED` without matched
  target runtime evidence.
