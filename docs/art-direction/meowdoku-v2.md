# Meowdoku — 猫爪手账美术与反馈支柱 v2

## 范围与玩法冻结

本轮只强化 `meowdoku`。题盘、给定数字、答案、选格、填数、擦除、错误计数、得分与胜利条件保持原逻辑；`sudoku` 和其余游戏不改。表现层只读取权威状态，并通过语义事件表现后果。

## 三个支柱

1. **一眼是猫咪手账，不是换色数独。** 棋盘必须先读成有猫耳、装订环、叠纸边和文具环境的完整物件；关掉动效后仍能辨认。
2. **纸、毛毡、印章形成同一种触感语言。** 棋盘、输入键、选择框、局部反馈与 GAG 猫爪奖励都服从软纸、粉色墨迹、奶油毛毡和少量金线的材质体系。
3. **安静思考，分级庆祝。** 常规选择与正确填数保持克制；错误、九宫完成、整局完成逐级扩大对象动画、环形动效、声音、振动与震屏，且每档可盲辨。

## 小型风格圣经

| 角色 | 规范 |
|---|---|
| 背景 | 既有粉色手账文具台；低对比度，让棋盘和数字先读 |
| 主物件 | 奶油纸、玫瑰粉、梅子色描边，圆角猫耳页与装订环 |
| 互动数字 | `DejaVu Sans` 数字字体；给定值深墨色，玩家值玫红并带墨迹下划线 |
| 中文反馈 | `NotoSansCJKsc-Subset` 的 `ui_cjk` 角色；动态文案固定到棋盘下方，禁止遮挡数字 |
| 主奖励 | GAG 生成的分层纸艺/毛毡猫爪，粉色肉垫、奶油纸边、梅子描线、金线针脚 |
| 动势 | 压下 → 回弹 → 扩散 → 归位；错误改为横向抓痕与短促抖动 |
| 禁止项 | 通用金币、魔法爆炸、跨游戏素材汤、纯色矩形换皮、文字烘焙进图片 |

## 反馈层级

| 等级 | 语义 | 对象与属性动画 | 屏幕/触觉 | 声音 |
|---|---|---|---|---|
| G1 | 选择、正确、擦除 | 单格压缩回弹、数字 1.18 倍回落、局部猫爪/橡皮轨迹 | 4–6 ms 轻振；无或极轻震屏 | 纸张点触、墨迹确认 |
| G2 | 错误 | 错误数字残影、单格横向抖动、撕纸抓痕 | 三段短振；约 1.4 px 衰减震屏 | 干燥修正刮擦 |
| G3 | 九宫完成 | 整宫纸面洗色、双环扩散、GAG 猫爪盖章并回弹 | 三段中振；约 3.4 px 衰减震屏 | 压印声 |
| G4 | 整局完成 | 九宫依次盖印、金色全盘洗色、中央 GAG 猫爪、专属结果卡 | 五段强弱节奏；约 5.8 px 衰减震屏 | GAG 毛毡猫爪 + 三颗暖木铃，程序完成音仅作低音量垫层 |

反馈形式是该游戏语义的实现，不是全目录硬模板。后续游戏应保留“等级可辨、意图/冲击/回落可证”的约束，但重新选择与其材质和动作相符的反馈手段。
