# Classic 2048 v2 runtime audit

The evidence in this directory was captured at the production portrait viewport
through the Godot compatibility renderer. Generated source files do not count
as evidence; the selected frames show the assets in the live game.

- `00_stable_material_family.png`: birch, amber, blue enamel, and purple
  masterwork GAG tile tiers with live runtime numbers.
- `10`–`13`: legal slide intent, travel, impact, and settle.
- `20_grade2_amber_merge.png`: routine promoted merge.
- `30_grade3_blue_milestone.png`: milestone boundary with promoted feedback.
- `40`–`43`: grade-four gather, visible GAG wood-shaving burst, rebound, and
  clear settled board.
- `grade4-masterpiece.webm`: the 24 pinned 60 Hz samples of the full peak
  envelope. Pinning prevents PNG encoding time on the software renderer from
  aging the effect out between captures. The audit tool regenerates the raw
  PNG sequence; it is intentionally not retained in Git after encoding.
- `50_locked_rejection.png`: blocked direction feedback with board and move
  count unchanged.
- `semantic-snapshot.json`: final rule state, event semantics, and runtime asset
  manifest.
- `performance.json`: comparative empty/full/busy llvmpipe trace.
- `online-aliyun.png` and `web-acceptance.json`: the fingerprinted Aliyun
  release booted in Chromium/SwiftShader, opened into classic 2048, with secure
  context and WebAssembly true and no console or request failures.

Human inspection on 2026-08-20 confirmed that the four material tiers remain
distinct at gameplay size, all values are readable, the GAG wood-shaving asset
is visible behind (not over) the result, routine feedback is quieter than peak
feedback, and the peak effect clears back to a legible board.
